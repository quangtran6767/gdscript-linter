## Decisions

- Use W10's permitted formatted-input implementation: offer a full-file
  reorder fix only when `fix::is_formatted` succeeds with the file's
  EditorConfig settings, then call `format_gdscript` with `reorder_code`.
  Unformatted files are reported without a fix. Declaration bodies retain
  their formatting; fixed formatted inputs match `gdguard --reorder-code`.
- Compare the plan's items with their source-child order, including split
  inline extends and class docstrings. No second ordering implementation.
- Initializer checks use the syntax tree, including `self.member`, call
  arguments and subscripts; attribute names on other objects are not member
  reads. Only variables have declaration-ordered initialization; moving
  methods and compile-time declarations remains safe.
- Follow W10's explicit bare-alias exception literally: moving
  `@export var b = a` above `var a = 1` is Safe; computed reads such as
  `a + 1` are Unsafe. Both examples have regression tests. Other computed
  member-variable reads whose target ends up later are also Unsafe.
- Reject pre-W10 lint caches although the package version is unchanged, so
  a warm cache cannot hide the new default warning. Include formatter
  EditorConfig settings in cache keys while this rule is enabled, since
  indent style, quote style and other formatting settings affect its fixes.
- Reviewed all added existing-fixture diagnostics: public before private
  constants/variables/functions, virtual methods before ordinary methods,
  methods before inner classes/top-level expressions, and the all-rules
  fixture's late variable before methods. Kept those fixtures unchanged.
- The unused-argument fix fixture now places the virtual method first so
  its safe-only test continues to isolate argument renaming. The baseline
  line-insertion test inserts comments rather than a variable before its
  class header, preserving its original baseline assertion.
- The checked-in sample project is already ordered, so its e2e snapshots
  remain unchanged. The manual test deliberately misplaced its used signal
  only in a temporary copy.
